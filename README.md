# دعوة الزفاف | Wedding Invitation (HTML / CSS / JS)

## التشغيل
افتحوا `index.html` مباشرة بالمتصفح، أو ارفعوا المجلد كامل على أي استضافة (Netlify, GitHub Pages, ...).

## التعديل
كل التفاصيل بملف واحد: `js/config.js`
- الأسماء، التاريخ (`date` بصيغة ISO مع فرق التوقيت، مثال `2027-06-12T18:00:00+03:00`)، المكان، الخريطة، اللباس، القصة، الصور، الموسيقى.
- أي قيمة فاضية بتظهر مكانها `[لم يُحدَّد بعد]` — ما في معلومات مخترعة.
- العد التنازلي وزر "احفظوا الموعد" بيشتغلوا تلقائياً بس تحطوا `date`.
- الصور: ضعوها بمجلد `assets/` وأضيفوها بـ `gallery`.
- النصوص والترجمات: `js/i18n.js` (عربي RTL افتراضي + إنجليزي).

## تأكيد الحضور (RSVP)
بدون `rsvp.endpoint` الفورم تجريبي وبيقول بصراحة إنو ما حفظ شي. للتفعيل الحقيقي استخدموا خدمة مثل Formspree
وحطوا رابطها بـ `rsvp.endpoint` (الفورم بيرسل JSON بطلب POST ولا بيعرض رسالة نجاح إلا إذا السيرفر أكّد).

## علامة EvnQ العائمة
دائرة اللوغو أسفل اليمين، ثابتة مع التمرير، وبتفتح رابط انستغرام. الملفات: `js/badge.js` + `css/badge.css` + `assets/logo.png`.
لإضافتها لأي صفحة جديدة بالموقع ضيفوا بس:
```html
<link rel="stylesheet" href="css/badge.css">
<script src="js/badge.js" defer></script>
```
(الرابط وصورة اللوغو بتتغيّر من `badge` داخل `js/config.js`.)

## ملاحظات
- الخطوط من Google Fonts (بحاجة إنترنت)، وفي خطوط بديلة إذا ما توفرت.
- البوابة والورود مرسومة بالكود (SVG/CSS) بدون صور خارجية؛ ممكن تحطوا صورة خلفية للصفحة الرئيسية والختام من الإعدادات.
- الحركات بتحترم إعداد "تقليل الحركة" بالجهاز.

## بيانات تجريبية
الأسماء (لمى ويزن)، التاريخ (18 حزيران 2027)، القاعة والعنوان، التفاصيل وكل الصور (رسومات مولّدة بالكود) هي بيانات مثال.
بدّلوها من `js/config.js` وبصور حقيقية بمجلد `assets/` بنفس الأسماء أو بتغيير المسارات.
